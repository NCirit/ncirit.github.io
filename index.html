About

I'm a software and computer engineer working across embedded devices, computer vision, and desktop applications. I'm most at home solving problems where hardware, protocols, and software meet, from USB firmware and asynchronous I/O to the tools people use to control and inspect those systems.

Selected projects

USB3 Vision Camera System

Developed firmware and host-side software for a USB3 machine-vision camera built around the Cypress FX3. Worked on GPIF II data transfer, DMA, USB3 Vision framing, and asynchronous image capture with libusb, debugging problems across the device and host boundary.

Thumbpad Android and Windows

Created an app that turns an Android phone into a trackpad, keyboard, and media remote for a Windows PC over a local Wi-Fi network. Built the mobile app and Windows companion as a complete, usable product.

ADB UDP Forwarding

Modified ADB and adbd to support UDP port forwarding and reverse forwarding. This required working within the existing client, server, and device-side protocol rather than building a separate tunnel alongside it.
